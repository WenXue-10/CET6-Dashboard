# 🐱 学习工作台使用说明

> 这是「喵咪备考 · 六级陪伴打卡」网页工作台的使用说明。工作台负责**打卡、记录、云端同步**，本知识库负责**沉淀笔记、整理资料**，两者配合使用。

## 模块总览

| 页面 | 模块 | 用途 |
|------|------|------|
| 首页 | 仪表盘 | 考试倒计时、本周打卡、今日任务、备考进度、专注计时、学习时长图表 |
| 错题 | 错题本 | 按 5 科目分类管理错题 |
| 生词 | 生词本 | 生词录入、批量导入、今日复习抽背 |
| 资料 | 资料入口 | 官方预置资料 + 我的自定义资料 |

## 核心功能

- **打卡**：完成当日 5 项任务自动打卡，支持连续打卡统计（回溯 60 天）
- **生词本**：手动新增 / 拍照识别 / 语音录入 / 批量导入；今日复习随机抽 10 个未掌握词
- **错题本**：手动录入 / 拍照识别 / 批量导入，按听力、阅读、词汇、写作、翻译筛选
- **专注计时**：记录每日学习时长，≥60 秒可保存；支持手动补记
- **备考进度**：5 维度目标值（单词 6000 / 听力 40 / 阅读 80 / 写作 30 / 翻译 60），支持 ±1 / +5 快捷调整
- **数据同步**：账号云端同步

## 设计风格

- 暖橘主色 + 奶油米背景，橘猫吉祥物，温暖治愈、萌系陪伴
- 移动端优先，底部 Tab 导航（首页 / 错题 / 生词 / 资料）
