# 📖 生词本使用指南

> 对应工作台「生词本」模块，本笔记用于沉淀生词规则与复习方法，[[生词表]] 用于实际记录。

## 数据字段

| 字段 | 说明 |
|------|------|
| word | 单词（必填，最多 100 字符） |
| meaning | 释义（必填） |
| example | 例句（可选） |
| mastered | 是否已掌握（默认否） |
| reviewCount | 复习次数（默认 0） |
| lastReviewedAt | 上次复习时间 |

## 录入方式

1. **手动新增**：单词 + 释义 + 例句
2. **批量导入**：JSON 数组格式
3. **拍照识别**：AI 从图片提取单词/释义/例句，可编辑后保存
4. **语音录入**：录音转文字，短文本填单词、长句子填例句

## 批量导入模板

```json
[
  { "word": "abandon", "meaning": "v. 放弃，抛弃", "example": "He abandoned his car." }
]
```

## 复习流程

1. 每次随机抽取 **10 个未掌握单词**
2. 先看单词 → 点「显示释义」
3. 判断「不认识」/「记得了」
4. 记住的自动标记为「已掌握」并记录复习次数
5. 完成页：本次复习 X 个，记住 Y 个，继续加油！🐾

## 状态与筛选

- Tab：全部 / 未掌握 / 已掌握
- 标签：学习中（未掌握）· 已掌握（绿色）
