# ❌ 错题本使用指南

> 对应工作台「错题本」模块，按 5 科目分类沉淀错题，定期回顾防重犯。

## 数据字段

| 字段 | 说明 |
|------|------|
| subject | 科目（5 选 1） |
| source | 题目出处 |
| summary | 错题简述（必填） |
| analysis | 错因分析与心得 |

## 科目分类

| Key | 中文名 | 标签颜色 |
|-----|-------|---------|
| listening | 听力 | 橙 |
| reading | 阅读 | 绿 |
| vocabulary | 词汇 | 蓝 |
| writing | 写作 | 粉 |
| translation | 翻译 | 紫 |

## 批量导入模板

```json
[
  { "subject": "listening", "source": "真题2023年6月", "summary": "第5题没听清", "analysis": "连读没听出来" }
]
```

## 记录建议

- **出处必写**：哪年哪套真题/模拟卷，方便回查
- **错因归类**：词汇 / 连读 / 定位 / 理解 / 逻辑 / 时态等
- **定期回顾**：每周翻一次错题本，检验是否真正掌握
